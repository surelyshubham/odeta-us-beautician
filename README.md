# odeta-us-beautician

## Glow by Odeta

Responsive skincare studio homepage built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

- `npm install`
- `npm run dev`
- `npm run build`

## Deploy on Vercel

Import this repository in Vercel and use the Vite defaults. If the project settings need to be entered manually, use `npm run build` as the build command and `dist` as the output directory.

Treatment photography is loaded from Glow by Odeta's official GlossGenius service listings.
